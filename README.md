# LinkedIn Job Postings EDA

## Project Overview

This project performs Exploratory Data Analysis (EDA) on LinkedIn and Indeed job postings to understand hiring trends, in-demand skills, top companies, popular job roles, and job market opportunities in the Data Science domain.

## Objectives

* Analyze job postings data
* Clean and preprocess the dataset
* Identify top hiring companies
* Discover popular job locations
* Analyze in-demand job roles
* Determine the most requested technical skills
* Understand hiring trends over time

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Google Colab

## Dataset Summary

* Total Job Postings Analyzed: 1,012
* Total Columns: 6
* Data Sources: LinkedIn and Indeed

## Data Cleaning

* Removed 2 fully empty columns
* Removed 36 rows containing missing values
* Achieved zero missing values after cleaning

## Key Insights

### Top Hiring Companies

* Meta ranked #1 with 70 job postings
* Netflix, Amazon, and Google were among the leading recruiters

### Top Job Locations

* United States had the highest number of job openings
* New York and San Francisco were major hiring hubs
* Bengaluru emerged as the leading Indian city for Data Science opportunities

### Most In-Demand Job Roles

* Data Analyst
* Data Scientist
* Data Engineer

### Most Requested Skills

* SQL
* Python
* Machine Learning

### Hiring Trends

* Hiring activity occurred in waves
* Peak hiring period observed in June 2025

## Conclusion

The analysis highlights strong demand for Data Science professionals across global markets. LinkedIn dominated the job posting market, while SQL and Python emerged as the most valuable skills. Data Analyst roles showed the highest demand, and India demonstrated significant growth in Data Science hiring opportunities.
